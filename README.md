Нужен сам Tampermonkey

Если ещё не стоит: в Opera GX (в моём случае) проверь сначала addons.opera.com. Если там нет — понадобится расширение «Install Chrome Extensions» из магазина Opera, после него ставится версия из Chrome Web Store.

(chrome://extensions)

opera://extensions → Tampermonkey → Details → включи Allow access to file URLs.
Перетащи tripo3d_model_downloader.user.js в окно браузера — Tampermonkey перехватит и покажет страницу установки с кнопкой Install.

Две галки в панели — это includeNormals и largestMeshOnly.

keep normals (по умолчанию выключено)

Нормаль — вектор, указывающий, куда «смотрит» поверхность в данной вершине; от него зависит вся заливка светом. У Tripo нормали генерирует нейросеть, и они часто кривые: соседние вершины смотрят в разные стороны, из-за чего в Blender модель покрывается тёмными пятнами и рваными гранями, хотя сама геометрия нормальная.

Выключено — нормали в файл не пишутся вовсе, и Blender считает их сам из порядка обхода вершин (winding order). Получается ровное гладкое затенение. Это то же поведение, что было в v1, и в 9 случаях из 10 правильное.

Включать стоит, только если модель с намеренно резкими рёбрами (механика, архитектура, hard-surface) — там пересчёт «загладит» углы, которые должны остаться острыми. Тогда лучше взять оригинальные нормали и при необходимости почистить их в Blender вручную.

largest mesh only (по умолчанию выключено)

v1 всегда экспортировала ровно один меш — с наибольшим числом вершин. Для составных моделей (тело + одежда + оружие отдельными объектами) это молча выкидывало всё, кроме самого крупного куска. Один из багов, которые я починил: теперь по умолчанию забираются все видимые меши.

Галка возвращает старое поведение — на случай, если в сцене остался мусор, который мой фильтр по именам (grid, shadow, helper, backdrop…) не распознал, и он лезет в экспорт. Тогда включаешь её и получаешь только основную модель.

Что реально в сцене — покажет tripo.inspect(): таблица со списком мешей, их вершинами и текстурами. Если там одна строка — галка ничего не меняет; если несколько и все осмысленные — оставляй выключенной.
